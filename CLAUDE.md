# CLAUDE.md

The Mane Forecast (`themaneforecast`, a Team Mikey site): a personal static site on GitHub Pages:
a weather page for Mikey the gray Holsteiner's barn, made for the family.

- **No build, no server, no keys.** `index.html` + `static/`. Everything runs in the browser:
  `static/js/data.js` (zip lookup, fetching, 30-minute device cache, NWS day cards, the source
  comparison, day popups, the stall guard's rain hours), `ui.js` (page, popups, charts, place
  settings), `blanket.js`, `stallguard.js`.
- **Location lives only on the visitor's device** (`maneforecast.place.v1` in localStorage), set by
  "Use my location" (the phone's GPS, best when at the barn), a town name or a zip, through
  Open-Meteo's geocoder (not Esri/ArcGIS: its free tier forbids storing results), rounded to
  2 decimals. A zip lands in the middle of the zip's area (can be ~10 km off), so GPS or the town is preferred.
  The settings show the NWS forecast square so it can be checked against weather.gov. The repo and the page source must never contain a location, a town name
  or weather.gov links with coordinates.
- Sources: NWS (forecast, forecastGridData, forecastHourly) and Open-Meteo (GFS, ECMWF, ICON, GEM
  in one call, plus Neighcast's own request). OpenWeatherMap was dropped: a key can't be hidden in
  a static page. A Cloudflare Worker could bring it back later if wanted.
- Blanket: `static/js/neighcast.js` is GENERATED byte for byte from Neighcast's `app.js` (a `neighcast`
  checkout next to this repo)
  (rules + forecast code: decide, nights, nwsHourly, windChill...). Never edit it; run
  `python3 scripts/sync_neighcast_rules.py` (check) or `--write`. Mikey uses his own chart
  (`blanket.js` adds `CHART.mikey`: none 60+, sheet 55-60, light 100g 45-55, medium 200g 30-45,
  heavy 300g below 30, on what it feels like at his stall), not a coat chart; no "feels the cold"
  box, the fine-tune slider shifts the ranges. Shelter default: runin (his partly covered stall).
- Stall guard: a rain spell counts once it adds up to her amount (default 0.15 in): the wetter of
  the NWS total and the models' average total. It starts at the earliest hour any source flags
  (NWS chance >= 30% or a measurable 6-hour block, or a model >= 0.01 in). Leave-by = start - (drive + prep + spare),
  default 15 + 30 + 15. Overnight leave-by moves to her evening visit. "Stall guard is up" covers
  that rain spell only.
- The week is 10 cards: NWS's 7 days, then days 8-10 from the average of the four models
  (`modelDays` in data.js, `WEEK_DAYS = 10`), dashed and tagged "Less certain"; their popup skips
  the NWS-only wind and cloud charts. Set `WEEK_DAYS = 7` to go back to a 7-day week.
- Personal site: no outbound links beyond the footer's data credits; `noindex` keeps it out of search.
- Naming: lowercase words joined by underscores. Design: gateopenerguide palette (navy +
  `#5cb8ff`), Fraunces headings, Inter body; phones get one row per day, nothing scrolls sideways.
- branching: master only (Pages serves master).
- Later: a shared "Mikey" Google Calendar for stall-guard and blanket reminders. With no
  server this would need a small scheduled job holding a Google service-account key.
